# 英语 VLOG 短视频制作流程

可复用的 Codex skill：从英语 VLOG 原片制作双语字幕、知识点回听与讲解、无字幕盲听、抖音时间轴，以及成片确认后的竖版知识点总卡。

## 下载与使用

下载整个目录（或仓库 ZIP），将解压后的文件夹重命名为 `english-vlog-short-video`，再放入 Codex 的 `skills` 目录。调用 `english-vlog-short-video`，提供原视频和本集期数；讲解配音可在文稿确定后补充。

## 文件

- `SKILL.md`：制作流程与固定版式
- `references/production-and-qa.md`：逐集记录和成片检查
- `assets/`：系列兔子动画、分帧图及转场提示音

原视频、人物画面、配音、单集脚本和导出成片不在本包中。素材的权利可能不同于流程文档；公开下载不自动授予素材的二次分发或商业使用许可。使用前请核对相应授权。
